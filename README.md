# EasyDoDraw

그림 그리기 도구. Android 앱과 Windows PC 프로그램이 같은 기능으로 동작.

브러시(가져오기: Photoshop `.abr` · Procreate `.brush` · Krita `.kpp` · 클립 스튜디오 `.sut` · MyPaint · GIMP), 레이어 · 마스크 · 조정 레이어, 편집 가능한 텍스트, 선택 · 채우기 · 도형 · 퀵셰이프, 필터 · 변형 · 유동화, 애니메이션(어니언 스킨 · GIF), 타임랩스, PSD · OpenRaster 읽기 · 쓰기.

## 설치

[Releases](../../releases)에서 받아 설치.

| 파일 | 대상 |
|---|---|
| `EasyDoDraw-<버전>.apk` | Android 10 이상 |
| `EasyDoDraw-<버전>.exe` | Windows 설치 프로그램 |
| `EasyDoDraw-<버전>.msi` | Windows 설치 프로그램(MSI) |

- Android: 처음 설치 시 "출처를 알 수 없는 앱" 설치 허용 필요. Play 프로텍트가 검사 화면을 띄울 수 있음
- Windows: 서명되지 않은 설치 파일이라 SmartScreen 경고가 뜰 수 있음 → "추가 정보" → "실행"
- 업데이트는 새 파일을 같은 방식으로 덮어 설치. 작품 · 설정 유지
- 앱 안 업데이트 알림 없음. 설정 → 정보 → "새 버전 받기"로 이 페이지 열기
- Android 서명 인증서 SHA-256: `362d130ee7722a6221a18015ed1f26704b9a30dade62042a48ace31e7cd23b2a`

## 개인정보

- 수집 · 전송하는 데이터 없음. 계정 · 광고 · 사용 통계 · 오류 보고 없음
- 인터넷 권한 없음. 작품 · 설정 · 브러시 · 글꼴은 기기 안에만 저장(Android 앱 전용 폴더, Windows `%APPDATA%\EasyDoDraw`). 앱 삭제 시 함께 삭제
